# Machine Learning Models & Predictive Intelligence

## Overview
The AI service uses machine learning models for anomaly detection and Remaining Useful Life (RUL) estimation on high-frequency IoT sensor telemetry.

### Models
1. **Isolation Forest / One-Class SVM**: Unsupervised anomaly detection on vibration, temperature, and pressure signals.
2. **Random Forest / XGBoost Regressor**: Supervised Remaining Useful Life (RUL) estimation in operating hours.
